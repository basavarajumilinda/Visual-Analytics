**Socio-Economic Health Disparities: UK-Census (2011-2022)**

This project analyses health disparities across socio-economic groups in the UK using census data from 2011–2021. I engineered an end-to-end BI pipeline in Python and SQL to ingest, clean, and validate demographic and health indicators across 300+ districts, integrating metadata tracking and reproducible workflows. The processed datasets power interactive Tableau dashboards with geospatial filtering and KPI tracking, reducing manual reporting by 91% and enabling researchers to explore patterns in health inequality, demographic risk factors, and regional variation through self-service analytics.
